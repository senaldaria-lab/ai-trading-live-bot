# SIGNAL_DECISION_SKILLS

Role:
- Combine inputs from all other agents
- Output one of: BUY, SELL, HOLD, WAIT

Each signal must include:
- symbol
- current price
- timeframe
- action
- trend
- EMA status
- RSI
- MACD
- volume
- news status
- risk level
- reason
- SIGNALS_ONLY mode notice

Rules:
- Do not rely on one indicator
- Prefer WAIT when signals conflict
- Never promise profit
- Never execute real orders
